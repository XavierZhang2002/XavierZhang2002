## Hi there, I'm Zhenliang Zhang 👋 ![Profile views](https://komarev.com/ghpvc/?username=XavierZhang2002&label=Profile%20views&color=0e75b6&style=flat)

I'm a Master's student at [Peking University](https://www.pku.edu.cn), advised by [Prof. Xiaojun Wan](https://wanxiaojun.github.io/). My research focuses on **agentic post-training for large language models**. Previously, I worked on hallucination detection ([ACL 2025](https://aclanthology.org/2025.acl-long.880/)), causal analysis of hallucinations ([CIKM 2025](https://dl.acm.org/doi/10.1145/3746252.3761298)), and copyright protection via internal semantic space control ([AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/view/40793)).

Currently, I am an intern on the [**Ling Team**](https://www.ant-ling.com/en/) at **Ant Group**, working on foundation model post-training to improve Agent Instruction Following (IF). Previously, I was a research intern at **Tencent WeChat**, where I developed **SCOUT** ([ICML 2026](https://xavierzhang2002.github.io/scout-page/)), an agentic active information foraging paradigm for million-token long-text understanding.
